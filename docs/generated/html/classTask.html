Detailed Description

Leaf of the Composite, Context of State and Strategy, and ConcreteComponent of Decorator.

A Task never decides what an operation does: it hands the call to its current TaskState, which either performs it (and calls handleChange() with the next state) or throws std::logic_error for an invalid operation.
