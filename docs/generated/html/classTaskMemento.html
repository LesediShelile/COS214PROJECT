Detailed Description

Memento capturing a private snapshot of a Task prior to command execution.

Part of the Memento design pattern. Preserves the internal state of a Task (originator), including its lifecycle state, current assignee, and data attributes. Construction and inspection are restricted to Task via friendship, ensuring encapsulation is preserved. The memento assumes ownership of the contained TaskState, which must be a cloned instance, while storing a non-owning pointer to the assignee. Instances of TaskMemento are managed and owned by WorkflowCommand (the caretaker).
