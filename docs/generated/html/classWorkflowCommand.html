Detailed Description

Abstract base class representing an undoable action on a work item.

Implements the Command design pattern. Represents an action on a WorkItem as an object that can be executed, recorded in history, and undone. Acts on the WorkItem abstraction (rather than concrete Task directly) so that decorated items can also be targeted. Before modifying the item, a command captures a TaskMemento snapshot, which is restored during undo(). The command owns the lifecycle of its captured memento.
