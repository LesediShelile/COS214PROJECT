enum class EventType
strong

Kinds of events published through the Observer pattern.

Every WorkflowEvent carries one of these, so listeners (audit logger, metrics collector, notifier, engine router) can decide what to react to.

Enumerator
ITEM_STATE_CHANGED 

An item moved to a new lifecycle state (details = new state name).

ITEM_COMPLETED 

An item reached the Completed state.

The engine uses this to activate the next item(s) in the workflow.

TASK_ACTION 

Something was done to a task and recorded by AuditedTask.

EXTERNAL_EVENT 

something outside TIVIDY happened

TIMEOUT 

An approval request ran out of time before it was answered.

WORKFLOW_FINISHED 

The whole workflow instance finished (details = outcome).
