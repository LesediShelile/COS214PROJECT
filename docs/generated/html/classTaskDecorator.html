Detailed Description

Decorator base: wraps another WorkItem and forwards every call to it.

Concrete decorators (ValidatedTask, AuditedTask, PriorityTask) override only what they extend.

The decorator owns the item it wraps. Its copy constructor clones the wrapped item, so a concrete decorator's clone() is simply return new MyDecorator(*this);.
