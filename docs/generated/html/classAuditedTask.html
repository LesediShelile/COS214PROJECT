Detailed Description

Concrete Decorator: publishes a WorkflowEvent after every successful lifecycle operation on the wrapped item, so listeners (AuditLogger, MetricsCollector, Notifier) see it without the task knowing them.

If the wrapped operation throws (an invalid transition, say), nothing is published, so the audit trail only records what actually happened. The publisher is shared, not owned. A NULL publisher makes this a no-op.
