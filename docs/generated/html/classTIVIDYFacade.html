Detailed Description

Facade providing a unified entry point to the TIVIDY workflow engine subsystem.

Clients register definitions and participants, create and start instances, and act on work items by ID. They never touch the underlying builders, iterators, commands, listeners, or approval chains directly.

The facade manages the lifecycle and owns every definition, instance, participant, and router registered with or created by it. Listeners (audit, notifier, metrics) are members, and instances hold non-owning references to them.
