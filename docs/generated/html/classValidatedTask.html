Detailed Description

Concrete Decorator: refuses to complete a work item until every required data field has been filled in.

Example: a doctor cannot complete "Assessment and treatment" until "diagnosis" and "disposition" are set. Every other operation is forwarded unchanged. The required fields are plain data, so the engine and the scenario never need a ValidatedTask subclass per rule.
