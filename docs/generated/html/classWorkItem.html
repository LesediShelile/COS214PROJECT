Detailed Description

Component of the Composite pattern (also Component of Decorator, Aggregate of Iterator, Prototype, Receiver of Command and Originator of Memento).

Every piece of work in a workflow, whether a single Task or a whole Stage, is a WorkItem. The engine only ever talks to this interface, so it never needs to know whether it holds a leaf or a group.

Ownership: whoever holds a WorkItem* owns it, except where a method says otherwise. A Stage owns its children and a TaskDecorator owns the item it wraps.
