Detailed Description

Invoker in the Command pattern responsible for executing commands and managing rollback history.

Runs workflow commands and maintains successful executions within an internal CommandHistory instance to support single-level or multi-level undo operations.

void CommandInvoker::executeCommand ( WorkflowCommand *  command)

Executes a command and stores it in history upon success.

Executes a given workflow command and tracks it in history for undo capability.

Takes ownership of the passed command. If execution throws an exception, the command is safely deleted and excluded from history.

Parameters
[in]commandPointer to the WorkflowCommand to run.

Employs std::unique_ptr during execution to ensure exception-safe cleanup. If execution completes successfully, ownership transfers to the internal CommandHistory.

bool CommandInvoker::undoLast ( )

Undoes the most recently executed command in the history.

Pops and undoes the most recently executed workflow command.

Discards the command after undoing (no redo functionality). If the undo action throws an exception, the command is discarded and the exception propagates.
