Detailed Description

Interactive, Menu-Driven Terminal User Interface (TUI) for TIVIDY.

Replicates the full scenario demonstrations without hardcoded configurations. Allows users to dynamically configure personnel quantities, select or create custom tasks, organize sequential and parallel execution groups, apply GoF decorators, execute workflows, and persist reusable custom scenarios across sessions.
