TIVIDY stores workflow {\itshape definitions}, creates independent running {\itshape instances} from them, routes work to participants, enforces multi-\/level approvals, reacts to events, talks to external systems and keeps a full history that can be undone.

The engine is generic\+: {\bfseries{nothing in the core mentions an industry.}} We prove it by running two completely different industries on the same engine\+: a hospital {\bfseries{emergency patient admission}} and a {\bfseries{legal case}}. Only the workflow definition, the roles and the data change.\hypertarget{md_README_autotoc_md3}{}\doxysubsection{\texorpdfstring{📑 Table of Contents}{📑 Table of Contents}}\label{md_README_autotoc_md3}

\begin{DoxyItemize}
\item {\bfseries{Definition vs instance.}} A {\ttfamily Workflow\+Definition} is frozen once built and owns the root of a {\ttfamily Work\+Item} tree. Creating an instance clones that tree, so every {\ttfamily Workflow\+Instance} has its own state, assignees and data. Running instances keep the definition version they started with.
\item {\bfseries{Nested work.}} {\ttfamily Task} is the leaf and {\ttfamily Sequential\+Stage} and {\ttfamily Parallel\+Stage} are composites. The engine treats every {\ttfamily Work\+Item} the same way and never checks types.
\item {\bfseries{Changing behaviour.}} {\ttfamily Task\+State} controls the task lifecycle, assignment is a Strategy, approval and escalation are a Chain of Responsibility, and Decorators add validation, auditing and priority.
\item {\bfseries{Reacting to events.}} Tasks publish {\ttfamily Workflow\+Event}s and independent listeners handle routing, audit, notification and metrics.
\item {\bfseries{History and recovery.}} Every action is a Command with {\ttfamily undo()}, and each keeps a Memento of the work item taken beforehand.
\item {\bfseries{External systems.}} The engine only knows {\ttfamily External\+Connector}. Adapters translate it to each external system.

\hypertarget{md_README_autotoc_md7}{}\doxysubsubsection{\texorpdfstring{Ownership rules}{Ownership rules}}\label{md_README_autotoc_md7}

\begin{DoxyItemize}
\item A {\ttfamily Stage} owns its children, and a {\ttfamily Task\+Decorator} owns the item it wraps.
\item Iterators and mementos returned by {\ttfamily create...()} functions belong to the caller, who must {\ttfamily delete} them. {\ttfamily Command\+Invoker} takes ownership of the commands passed to {\ttfamily execute\+Command()}.
\item {\ttfamily clone()} copies work state, data and children. Shared configuration (roles, strategies, participants, the event publisher) is pointed to, not copied.
\item {\ttfamily Stage\+::assign/start/complete/reject} throw {\ttfamily std\+::logic\+\_\+error}, because those only make sense on a task. {\ttfamily make\+Available()} and {\ttfamily cancel()} act on the children.

Open {\ttfamily coverage\+\_\+report/index.\+html} in a browser to see line and function coverage per file.\hypertarget{md_README_autotoc_md17}{}\doxysubsection{\texorpdfstring{🏥 The demo scenarios}{🏥 The demo scenarios}}\label{md_README_autotoc_md17}
{\bfseries{Hospital emergency admission.}} Paramedic pickup and transport, patient registration, room preparation in parallel with transport, handover, nurse intake, doctor acceptance (with a deadline and reroute), assessment and treatment, room allocation (ICU and surgery need approval) and cleaning. Failure paths cover a delayed ambulance, a doctor who does not respond and a deteriorating patient. The outcome is a patient admitted, transferred, discharged or recorded as deceased, with the full history archived.

{\bfseries{Legal case.}} Client intake, conflict check, parallel discovery (evidence and legal research), drafting, partner review, filing, hearing, judgment, invoicing and archiving. It includes a rejected-\/pleadings exception path and a cancelled filing.

{\bfseries{Participants\+:}} paramedics, secretary, nursing staff, doctors, cleaning staff, lawyers, partners. {\bfseries{External systems\+:}} ambulance dispatch and hospital patient records, reached through adapters.

Only the definitions, the adapters and their APIs know about an industry. The engine runs both processes without changes.
